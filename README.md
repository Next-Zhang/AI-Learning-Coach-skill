# python-coach

一个陪你按计划学习 Python 的 AI 教练 skill。它把学习目标转成每日任务，通过实操证据验收、学习画像更新和间隔复习，形成 **计划 → 执行 → 反馈 → 验收 → 总结** 的闭环。

项目目前处于 **skill 阶段**：AI agent 负责对话、教学与流程编排，Python 脚本负责计算、文件更新和校验，Markdown 文件保存学习状态。每日生成的 HTML 是可离线打开的任务视图；完整学习流程由支持加载 skill 的 agent 环境执行。

## 能帮你做什么

- **围绕实际目标学习**：先明确“想用 Python 做什么”，约定覆盖与不涉及的内容，再安排课程。
- **从你的起点出发**：通过问卷和摸底测试建立画像与能力矩阵，识别前置知识缺口并安排补学。
- **每天带着任务学习**：生成包含概念、示例、目标清单和参考来源的执行网页，陪你动手、纠错和完成练习。
- **用证据判断完成情况**：结合代码、运行结果或回答逐项目标验收，展示评分依据，允许质疑和复核。
- **把学习结果带到下一天**：保存每日总结、知识点掌握度、复习快查文档与复习时间表。

例如，你可以提出：“我想用 Python 处理 Excel 报表，每天能学 45 分钟。”教练会先澄清目标和范围、了解起点，再生成学习计划。

## 整体设计

```text
学习者：目标、问卷回答、练习证据、自评、难度反馈与确认
                         ↓
AI 教练：澄清 → 摸底 → 规划与评审 → 教学 → 验收 → 复习
                         ↓
Python 脚本：检索 / 评分 / 画像更新 / 网页 / 复习文档 / 调度 / 核对
                         ↓
当前学习工作区：计划、画像、进度、资料、复习文档与调度表
                         ↓
下一学习日的新会话读取状态，继续学习
```

| 部分 | 职责 | 入口 |

## 安装与开始使用

### 环境准备

- **Python 3.12 或更高版本**。脚本只使用标准库，无需安装第三方 Python 包；本次回归使用 Python 3.12.14。
- 一个能加载 `SKILL.md`、读写学习工作区并执行 Python 脚本的 agent 环境。现有流程按 **DeepSeek Harness（DSH）** 编写。
- 计划的三验证需要独立子代理能力；本地资料不足时，网络检索由 agent 环境提供，脚本自身不联网。

### 安装 skill

将以下内容复制到 DSH 的 `~/.dsh/skills/python-coach/`，保留目录名 `python-coach`：

```text
SKILL.md
resources/
scripts/        # 含测试与 testdata 夹具，排除 testdata/_out/ 和 __pycache__/
templates/
docs/
CONTEXT.md
README.md
LICENSE
```

`.git/`、`.scratch/` 和学习者运行数据不放入技能包。当前采用目录复制式安装，仓库没有安装器或打包命令。其他 agent 环境需要适配 skill 加载、工具和权限约定，本仓库未验证这些环境的完整流程。

在你的**学习工作区**中开启新会话，输入：

```text
python-coach
```

也可以同时说明意图：

```text
python-coach，我想用 Python 处理 Excel 报表，每天能学 45 分钟。
```

## 使用流程

### 1. 首次使用：建立学习计划

1. **初始化状态**：教练按模板建立当前工作区的学习数据。`source.md` 和 `review-sheet.md` 是后续资料与复习文档的模板，不是预置课程。
2. **回答起步问卷**：一问一答收集 8 项信息，包括学习目标、Python 水平、每日时间、学习风格、压力承受、期望节奏、过往经历和复习意愿。你可以中途修改回答。
3. **澄清目标与范围**：把目标落到具体用途，明确要学什么、不涉及什么，由你确认后形成计划草案。
4. **完成摸底测试**：在约定范围内完成 15–20 题，结合选择、简答和实操题，建立知识点评分与前置能力状态。
5. **查看计划与独立评审**：教练生成按天划分的任务，每天都有主题、目标、知识点、前置与来源。独立评审 agent 检查真实性、合理性和适配性，最多进行 3 轮评审与修订。
6. **确认终稿**：评审与自检通过、你确认后，计划生效，开始首日学习。验证未通过时保留草案与问题，不把计划标为生效。

### 2. 每个学习日：复习、热身、动手学习

每天新开一个会话并调用 `python-coach`。教练读取当前计划、画像、进度和调度表，定位当日任务，然后依次执行：

1. **行前核对**：检查知识点引用和前置条件。严重缺口暂停原任务并调整计划补学；轻度缺口先做简短导入。
2. **到期复习**：按调度表逐题考察，给出 `pass/fail` 与理由。全部考完后展示结果单，你确认后更新掌握度与复习日期。
3. **随机热身**：从已学、未到期的历史知识点抽取最多 2 个快问快答。热身不计分、不写回；没有合适候选时跳过。
4. **生成当日网页**：提供概念与示例、学习链路、今日目标清单、参考来源四个区块，可离线打开。
5. **完成当日任务**：你动手练习、提交结果或报错，教练提供提示、纠错和必要示范。教学以当日任务和已确认范围为边界。

网页勾选只用于当日查看；正式进度通过后续验收写入。网页自包含可离线展示，外部参考链接的访问仍需要网络。

### 3. 当日收尾：验收与总结

1. **提交证据**：提供代码、运行结果或回答，教练逐项目标核查，说明“完成 / 部分完成 / 未完成”及理由。
2. **自评与难度反馈**：你给出 1–5 分自评，并反馈“太难 / 刚好 / 太简单”。
3. **查看合成分与复核**：完成度 = `教练评分 × 0.7 + 自评 × 0.3`，四舍五入到 0.5 分档。难度反馈独立记录；你可以质疑评分并要求复核。
4. **确认后写回**：更新能力矩阵，追加每日总结与结构化证据，生成课程复习快查文档，将新知识点加入复习调度。
5. **清理当日网页**：总结完成后，教练提出删除临时执行网页，经你明确批准后删除。

知识点验收完成度达到 4 分时，已有矩阵行的水平分增加 0.5，最高 5 分。发现矩阵外的新知识点时，先说明并取得确认，再走新增与配套同步流程。

### 4. 跨日复习：按掌握情况推进

- 新知识点先安排在 1 天后复习。
- 通过考察：掌握度增加 0.5，间隔按 **1 → 3 → 7 → 15 → 30 天**推进，30 天档继续保持。
- 未通过：掌握度减少 0.5，间隔重置为 1 天；评分范围为 1–5。
- 复习快查文档按课程保存，包含概念、关键代码、常见坑与来源，支持按知识点或日期查询。
- 二值前置能力与带分数的知识点分开处理；能力行不进入间隔复习调度。

## 学习数据保存在哪里

```text
学习工作区/
├── .python-coach/
│   ├── state/
│   │   ├── plan.md             # 目标、范围与每日计划
│   │   ├── profile.md          # 问卷、能力矩阵与增量记录
│   │   ├── progress.md         # 每日总结与验收证据
│   │   ├── decision-log.md     # 运行期关键决策，按需建立
│   │   ├── sources/            # 带来源元数据的学习资料
│   │   └── review/
│   │       ├── schedule.md     # 复习调度表
│   │       └── NN-主题.md      # 每课复习快查文档
│   └── tmp/                    # 输入输出 JSON、草稿、评审包等过程文件
├── exercises/                  # 每日练习
└── project/                    # 综合项目交付物
```

“六件套”指计划、画像、进度、资料目录、复习目录及其调度表，不是六个模板文件直接复制到同一目录。日期与个人信息的模板占位符由起步流程填写。

持久数据修改需学习者确认，删除需明确批准；过程文件按阶段清理，当日执行网页单独确认删除。跨日通过状态文件衔接，跨工作区不继承学习画像。完整格式与路径规则见 [数据格式契约](resources/data-formats.md)。

## 开发与维护

仓库根目录包含 skill 入口与 README；`resources/`、`scripts/`、`templates/` 保持运行时引用稳定；`docs/adr/` 保存设计决策，`.scratch/python-coach/` 保留原始规格和开发票据作为历史依据。

在仓库根目录运行全部回归测试：

```powershell
python -B -m unittest discover -s scripts -p "test_*.py"
```

测试输出在已忽略的 `scripts/testdata/_out/`。本次审查 **225 项测试通过**；这些测试覆盖脚本文件契约，对话教学与独立评审的实际效果仍需人工演练。
