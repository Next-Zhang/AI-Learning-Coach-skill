## 项目理解与范围

python-coach 是由 agent 对话编排、7 个 Python 脚本、Markdown 状态和契约组成的学习教练 skill。首次起步建立画像与计划，每日会话先核对前置与复习，再教学、验收、总结；学习数据按工作区隔离。

本次阅读了 skill 入口、现有 README、数据与流程契约、脚本实现、测试结构、领域词汇和历史修订方案。执行全部脚本回归，并对检索和网页渲染做边界检查。未重新演练完整教学或独立计划评审。

| 优先级 | 问题与影响 | 依据 / 后续方向 |

| P1 | 多文件写回缺少事务与失败恢复。复习先更新调度表再更新画像，第二步失败会留下部分写入；盲目重跑可能重复加分或推进间隔。 | `session-start-contract.md` §4.4；`schedule.py`、`profile.py` 分别写文件。后续需要写前校验、恢复策略与幂等标识。 |
